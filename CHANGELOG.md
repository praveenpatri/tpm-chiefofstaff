# Changelog

## 0.5.0
- Connectors: `.mcp.json` for Atlassian (Jira, Confluence) and Google Calendar; snapshot store; dependency and meeting analyzers; `.ics` import; Ticket column for dependencies.
- Scheduler: cron and event triggers, headless Claude runs, native indexer and digest jobs.

## 0.4.0
- Storage adapters (local, Google Drive, OneDrive, S3) and a mirror sync with conflict detection and soft removals.

## 0.3.0
- Slack app (Socket Mode): cited answers, `/tpm` commands, draft approvals with target channels, `/tpm new`, scheduled digest, optional per-agent apps; optional Slack step in program setup.
- PARA program layout and the linked-files register.

## 0.2.0
- Chief of Staff, Second Brain, Mentor, named agents, portfolio dashboard.

## 0.1.0
- Program templates, setup/program/portfolio skills, sub-agents, indexer.
